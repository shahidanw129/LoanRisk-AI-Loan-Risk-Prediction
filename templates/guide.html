GUIDE

How to Use

Follow these simple steps to explore the LoanRisk AI application.

1

Enter applicant details

Open the Predict page and enter the applicant's financial and profile information.

2

Click Predict Loan Risk

The Flask application sends the form data to the trained Random Forest model.

3

View the risk category

Review the predicted category and model probability percentages.

4

Explore data insights

Use the Analysis page to understand patterns in the training dataset.

5

Learn about the project

Visit About for the dataset, model, accuracy and technology details.

💡

Educational Note

This project is intended for educational and learning purposes. It uses a reproducible sample dataset and a machine learning model. It is not a real financial approval system.
