# LoanRisk AI - IBM BOB Project

## Project intent
Build and maintain a complete educational loan-risk prediction application.

## Stack
- Python + Flask
- Pandas + NumPy
- Scikit-learn Random Forest
- Matplotlib
- HTML/CSS/JavaScript

## Important rules
- Keep the UI close to the supplied LoanRisk AI reference design.
- Do not hard-code prediction probabilities.
- Retrain with `python train_model.py` when dataset/model logic changes.
- Keep charts generated from the real dataset.
- Test Flask routes after changes.
