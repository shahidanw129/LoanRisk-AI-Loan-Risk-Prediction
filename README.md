
# LoanRisk AI – Loan Risk Prediction and Analysis

A complete IBM BOB-style AI/ML project that predicts loan risk using a
Random Forest classifier and provides a responsive five-part web experience.

## Features

- Home/Dashboard with reference-style navy navigation and statistics
- Real Flask prediction endpoint
- Random Forest loan-risk classifier
- Low / Medium / High Risk classes
- Dynamic probability output from the trained model
- Dataset-driven analysis charts
- About page with model and dataset information
- Usage Guide
- Responsive desktop/tablet/mobile UI
- Light/dark theme toggle
- Input validation and error handling

## Dataset

The project uses a reproducible synthetic dataset of 4,200 loan applications.
It is generated by `train_model.py` so the project can be rebuilt without
downloading an external dataset.

Columns:
- Age
- Annual Income
- Loan Amount
- Credit Score
- Employment Status
- Loan Term
- Previous Loan History
- Debt to Income Ratio
- Loan Risk (target)

The target contains:
- Low Risk
- Medium Risk
- High Risk

## Machine Learning Method

1. Generate a reproducible sample dataset.
2. Separate input features and target.
3. Scale numeric features and one-hot encode categorical features.
4. Split into training/testing sets using stratification.
5. Train a Random Forest Classifier.
6. Measure test accuracy and classification metrics.
7. Save the complete preprocessing + model pipeline to:
   `model/loan_risk_model.pkl`
8. Generate four analysis charts from the dataset.

The UI displays the actual measured test accuracy; it is not hard-coded.

Whenever you change the dataset or training logic:

```bat

```

## How Prediction Works

The Predict page sends eight applicant values to Flask using JavaScript.
Flask loads the saved preprocessing + Random Forest pipeline, transforms
the input exactly as during training, predicts the risk class and obtains
class probabilities with `predict_proba()`.

The result card then displays:
- Risk category
- Low/Medium/High probabilities
- Credit score indicator
- Income stability indicator
- Loan amount ratio indicator
- Overall assessment

The probabilities are generated by the trained model and are not hard-coded.

## Troubleshooting

### `ModuleNotFoundError`
Activate the virtual environment and run:

```bat
pip install -r requirements.txt
```

### Model not found
Run:

```bat
python train_model.py
```

### Port already in use
Close the existing Flask terminal, or change the port at the bottom of
`app.py`.
